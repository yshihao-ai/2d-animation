# 2D Animation

An interactive explanation of two-dimensional autoregressive music generation.

**Live demo:** https://yshihao-ai.github.io/2d-animation/

A synchronized printer analogy highlights latent guidance from the Time Decoder and event-by-event generation by the Note Decoder. Includes English/Chinese, pause, stepping, scrubbing, speed control and looping.

Open index.html locally, or publish the main branch root with GitHub Pages. No installation or build is required.

The animation presents the conceptual feedback loop. A collapsible note documents the delayed-summary detail in the current DID implementation.
